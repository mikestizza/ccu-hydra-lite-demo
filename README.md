# Hydra-lite

A small, honest stand-in for CCU's **Hydra** staff application, built to show what the web tier looks like running as Linux containers on **Nutanix Kubernetes Platform (NKP)**.

It is not Hydra. It is the same *shape*: a .NET web app that talks to SQL Server, calls an in-house API, and runs background jobs in-process the way Hangfire does today.

```
                                   ┌──────────────────────── NKP cluster ─────────────────────────┐
  staff browser ──► F5 / Fortinet ─┼─► Traefik ingress ──► hydra-web (x2, Kestrel, .NET 10)         │
                                   │                          │            │                        │
                                   │                          │            └──► colby-api (x2)       │
                                   │                          │                  ClusterIP only,     │
                                   │                          │                  NetworkPolicy        │
                                   │                          └──► hydra-db  (SQL Server 2022 Linux) │
                                   │                                          PVC on Nutanix CSI     │
                                   └──────────────────────────────────────────────────────────────┘
```

## What it demonstrates

| Objective | Where to look |
|---|---|
| .NET web tier in a Linux container, no IIS | `src/HydraWeb/Dockerfile`, the **Platform** page in the app |
| Ephemeral environments per branch | push any branch; CI writes `deploy/envs/<branch>` and Flux creates `hydra-<branch>` |
| East-west traffic stays in-cluster | `deploy/base/colby-api.yaml` (ClusterIP + NetworkPolicy), `deploy/demo/netpol-probes.yaml` |
| Patching is an image rebuild and a rolling update | merge to main; CI bumps `deploy/envs/prod`, Flux rolls it |
| Secrets stay out of Git | `deploy/base/config.yaml` uses `${SQL_SA_PASSWORD}` substituted by Flux from a cluster Secret |
| Policy as code | `deploy/policy/` (Gatekeeper), `deploy/demo/bad-deployment.yaml` gets rejected |

## Layout

```
src/HydraWeb/        ASP.NET Core 10 Razor Pages: Dashboard, Members, Member detail, Background Jobs, Platform
src/ColbyApi/        Minimal API returning mock account data (stands in for an in-house ancillary API)
deploy/base/         Kubernetes manifests (namespace, SQL Server StatefulSet, colby-api, hydra-web, ingress, NetworkPolicy)
deploy/envs/prod/    Production overlay (image tags updated by CI)
deploy/envs/<slug>/  Ephemeral overlays, generated by CI per branch
deploy/flux/envs/    One Flux Kustomization per environment (prod.yaml plus generated ones)
deploy/policy/       Gatekeeper templates/ and constraints/ for hydra-managed namespaces
deploy/demo/         Things to run live during the demo
bootstrap/           The one-time cluster hookup (Flux GitRepository, Secret, ConfigMap)
docs/                Demo runbook
```

## Cluster bootstrap (once)

From a machine with `kubectl` pointed at the NKP workload cluster:

```bash
git clone https://github.com/mikestizza/ccu-hydra-lite-demo
cd ccu-hydra-lite-demo
INGRESS_DOMAIN=<traefik-lb-ip>.sslip.io ./bootstrap/bootstrap.sh
```

Flux then pulls `main`, creates the `hydra` namespace and brings up the app at `http://hydra.<traefik-lb-ip>.sslip.io/`.

## Day to day

- **Change prod**: merge to `main`. CI builds `ghcr.io/mikestizza/{hydra-web,colby-api}:main-<sha>`, updates `deploy/envs/prod/kustomization.yaml`, Flux rolls the Deployment with zero downtime.
- **Try something**: push a branch. CI builds `<branch>-<sha>`, writes `deploy/envs/<branch>/` and `deploy/flux/envs/<branch>.yaml`. Flux creates namespace `hydra-<branch>` with its own SQL Server and URL `http://hydra-<branch>.<domain>/`. Delete the branch and the namespace is pruned.
- **Break a rule**: `kubectl apply -f deploy/demo/bad-deployment.yaml` and watch Gatekeeper refuse it.

## Local run (optional)

```bash
docker run -e ACCEPT_EULA=Y -e MSSQL_SA_PASSWORD='ChangeMe_Local1!' -p 1433:1433 -d mcr.microsoft.com/mssql/server:2022-latest
export MSSQL_SA_PASSWORD='ChangeMe_Local1!'
cd src/ColbyApi && dotnet run --urls http://localhost:5081 &
cd src/HydraWeb && dotnet run --urls http://localhost:5080
```

All member data is fictional.
